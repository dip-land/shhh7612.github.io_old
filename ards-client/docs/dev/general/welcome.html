Pulls Posts from Reddit, Danbooru, rule34, Konachan, and Yande.re



This documentaion is for ards-client version 3 and later, for v1 and v2 docs click here.


If you are upgrading from version 1.x.x and 2.x.x, please read this guide on updating to version 3.x.x.

Installation

Node.js 14.0.0 or newer is required.
npm i ards-client
yarn add ards-client

Basic Usage

For Reddit

const { redditCustom } = require("ards-client");
let subreddit = ['subreddit1', 'subreddit2']; //Can be array of strings or a string
let limit = 50; //Always a number
new redditCustom(subreddit, limit).then(data => {
    console.log(data);
}).catch(error => {
    console.log(error);
});
