ArdsClient

Pulls Posts from Reddit, Danbooru, rule34, Konachan, and Yande.re

If you are upgrading from version 1.x.x and 2.x.x, please read this guide on updating to version 3.x.x.

Installation

Node.js 14.0.0 or newer is required.
npm i ards-client
yarn add ards-client

Basic Usage

Replace method with the method you want to use, all methods can be found here.
const { ArdsClient } = require("ards-client");
new ArdsClient().method().then(request => {
    console.log(request);
}).catch(error => {
    console.error(error);
});

or

const ards = require("ards-client"), ardsClient = new ards.Client();
ardsClient.method().then(request => {
    console.log(request);
}).catch(error => {
    console.log(error);
});
