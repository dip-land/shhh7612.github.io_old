Danbooru

Pulls Posts from Danbooru

Usage

Tags, max for danbooru is 2 tags, see Danbooru help:cheatsheet for more info. Limit, number of posts grabbed. Does not change the results themselves. The maximum limit for danbooru is 200. 
const ards = require("ards-client"), ardsClient = new ards.Client();
ardsClient.hentai.danbooru(tags, limit).then(request => {
    console.log(request);
}).catch(error => {
    console.log(error);
});
