Yandere

Pulls Posts from Yande.re

Usage

Tags, the tags to search for. Any tag combination that works on yande.re will work here. This includes all the meta-tags. Limit, number of posts grabbed. Does not change the results themselves. The maximum limit for yande.re is 100. 
const ards = require("ards-client"), ardsClient = new ards.Client();
ardsClient.hentai.yandere(tags, limit).then(request => {
    console.log(request);
}).catch(error => {
    console.log(error);
});
