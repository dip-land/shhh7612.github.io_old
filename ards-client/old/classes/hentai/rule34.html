Usage

Tags, the tags to seach for, vist Rule34 help:cheatsheet for more info. Limit, number of posts grabbed. Does not change the results themselves. The maximum limit for rule34 is 1000. 
const ards = require("ards-client"), ardsClient = new ards.Client();
ardsClient.hentai.rule34(tags, limit).then(request => {
    console.log(request);
}).catch(error => {
    console.log(error);
});
