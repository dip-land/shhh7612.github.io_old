Konachan

Pulls Posts from Konachan

Usage

Tags, the tags to search for. Any tag combination that works on konachan will work here. This includes all the meta-tags. Limit, number of posts grabbed. Does not change the results themselves. The maximum limit for konachan is 100. 
const ards = require("ards-client"), ardsClient = new ards.Client();
ardsClient.hentai.konachan(tags, limit).then(request => {
    console.log(request);
}).catch(error => {
    console.log(error);
});
